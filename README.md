# 乡土调查员 · 《乡土中国》田野探究工作坊

以费孝通《乡土中国》**整本书阅读**为载体的高中跨学科（语文 × 地理）探究平台。学生扮演青年田野调查员，走进 AI 生成的虚拟村落：**选章 → 驻村 → 访谈 → 空间语义分析 → 考察报告 → 教师评阅**，把书本概念落到聚落空间上亲手验证。

## 快速开始

- **file:// 直开**：双击 `index.html` 即可玩（零依赖零构建）。
- **本机服务**：双击 `启动.bat`（或 `node server.js`）→ http://localhost:8948 ，监听 0.0.0.0，手机局域网可访问。（8947 已被「图解地理」项目占用，故用 8948。）
- 数据存于浏览器 `localStorage`（键 `xiangtu1`），设置页可导出/导入存档。

## 玩法闭环（学生端）

1. **选章**：14 章卡片，每章配导读、3 张概念卡、可回查底本的原文节选、2 个探究任务。
2. **驻村**：4 类虚拟村落（北方黄土村·槐荫村 / 江南水乡村·荻塘村 / 闽赣客家村·围龙村 / 云贵山地寨·云岭寨），每村有手绘 SVG 鸟瞰图、地理背景档案、10 处可点击的空间要素。
3. **空间观察**：点要素答观察题（对照真值判分），再给要素贴概念标签。
4. **村民访谈**：每村 5 位身份各异的 NPC（村长/老农/教书先生/手艺人/返乡青年），自由提问，回答自动贴概念标签，一键收进素材库。
5. **语义分析**：把"我的标注"与"要素真值"逐项对照，出概念-空间对应表与得分，集齐满分标注点亮"地理发现"。
6. **考察报告**：离线生成器把素材结构化重组为五部分初稿（绝不虚构素材之外的事实），学生编辑、初评（规则评分+修改建议）、提交。
7. **概念罗盘**：42 个核心概念一张图（石绿＝掌握、赭金＝将破、空心＝未通）——答题、标注、访谈、报告、探案都会计入证据，薄弱概念自动给「回读/观察/访谈/报告」补强路线。
8. **调查本（驻村探案）**：槐荫村「花椒药害案」——8 处地点、16 条证言、追问链解锁关键矛盾，写四节结案陈词（案由/双方说法/矛盾与查证/依礼评理）。
9. **区域对比 / 成就图鉴**：任意两村差异表；15 枚成就 + 5 级调查员称号（乡土学徒 → 乡土观察家）。

## 教师端

- 学情看板（种子化**模拟演示数据**，已明确标注）、任务发布、报告评阅（AI 初评 + 人工终审/打回/评为优秀）、优秀成果集。

## AI 双模式

- **离线引擎默认**（零网络零密钥）：NPC 对话=身份口吻模板 + 关键词规则库（每村 5 人 × 6-8 条规则，答错身份/超出知识边界自然回落）；报告=素材结构化重组；全部确定性，可离线批量回归测试。
- **可选 API**：设置页填 OpenAI 兼容接口（默认智谱 glm-4-flash）即可启用；4 组提示词（NPC 对话 / 空间分析解说 / 报告润色 / 教师学情分析）内置可复制；失败自动回落离线引擎并在界面注明。

## 考据纪律

- 全站引文逐字取自 `资料/底本合并/gx_*.txt`（国学导航版底本，双源核验过程与弃用方案留痕见 `report/考据说明.md`）。
- `test/test.js` 对每条节选、每日一句做**底本子串回归**；NPC 语料设"概念学名黑名单"（村民不许说出"差序格局"这类书里才有的词——概念要由学生自己贴上去）。
