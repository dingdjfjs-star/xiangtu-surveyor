## 1. 这个项目是什么（30 秒版）

把费孝通《乡土中国》的 14 章，变成 4 个可以"走进去"的虚拟村落：学生选章→驻村→在 SVG 手绘地图上做空间观察→和 20 位 AI 村民访谈→把概念标签贴到空间要素上对照真值→生成五部分考察报告→教师评阅。全程离线可用（确定性规则引擎），可选接入大模型 API。

一句话架构：**数据层（data-*）+ 纯逻辑引擎（engine）+ 浏览器薄壳（ui）**，零依赖零构建。

## 2. 三明治架构：为什么引擎必须零 DOM

```
index.html
├── js/data-book.js        14 章：导读/概念卡/节选/任务        ← 只放数据
├── js/data-village-v1..4  4 村：地理档案/SVG要素/NPC规则库     ← 只放数据
├── js/data-villages.js    聚合 + 查询助手（conceptPool 等）
├── js/data-prompts.js     4 组 AI 提示词 + 离线说明
├── js/engine.js           状态机/对话/分析/报告/成就           ← 纯逻辑，零 DOM
└── js/ui.js               hash 路由 + 全视图 + SVG 绘制        ← 只做展示
```

三条铁律：
1. **engine.js 禁止出现 `document.` / `fetch(`**（测试第⑮组静态扫描把关）。为什么？因为 Node 里 `node test\test.js` 直接 `require` 引擎就能跑全部逻辑断言——UI 不在场，引擎照常工作。这是 792 项断言能存在的前提。
2. **数据文件同构双端**：每个 data 文件写 `(function(global){...})(globalThis)`，同时挂 `window.XT_*` 和 `module.exports`——浏览器 `<script>` 和 Node `require` 各取所需。
3. **UI 只调引擎 API**：`ui.js` 里没有一处业务判断（比如"观察对不对"），全部委托 `XT_ENGINE.observe(...)` 返回 `{ok, exp}`。

## 3. 考据闭环：引文怎么做到"逐字可回查"

这是全项目最硬的一环，管线五步：

```
tools/fetch-source.mjs   抓底本（GBK 解码、导航表格剔除、顺"下一页"链）
    ↓
资料/底本guoxue/          原始抓取（带来源头，证据存档）
    ↓
tools/clean-sources.mjs   清洗成纯正文 → 资料/底本合并/gx_*.txt
    ↓
js/data-book.js           每条 excerpts.text 逐字摘自底本
    ↓
test/test.js 第③组        每条节选 + 每条每日一句 → 底本子串匹配，失配即红
```

三个实战教训：
- **多源交叉核验**：先抓了番茄小说版，比对后发现它用自定义字体做字符混淆（正文"乡土农弯腰收割稻"式缺字）——弃用留痕，只信国学导航版；5 句最著名原文再用搜索引擎独立抽查一遍。
- **"名言"不可信**：网络流传的《乡土中国》金句常有拼接改写，全部以底本子串匹配为准。
- **底本笔误不改字**：数字化底本有"威尼思""身分"这类字词，原则是不动底本字句，节选边界避开笔误密集处，并在考据说明留痕。

## 4. 离线 NPC 引擎：确定性怎么设计

每个 NPC 是一张卡：`{身份, 口吻, knows, blind, rules[], fallback[]}`。每条规则：`{kws:['祠堂','祖先'], concept:'c08b', say:'…', follow:['追问1','追问2']}`。

```js
function pickRule(npc, question) {
  const q = normQ(question);            // 去标点空白、转小写
  let best = null, bestHits = 0;
  for (const r of npc.rules) {
    let hits = 0;
    for (const kw of r.kws) if (q.indexOf(normQ(kw)) >= 0) hits++;
    if (hits > bestHits) { best = r; bestHits = hits; }   // 命中数最多者胜，并列取声明序
  }
  return best;
}
```

三个关键决策：
1. **回落句不采集**：`collectMaterial` 里 `if (answer.isFallback) return null`——闲聊不进素材库，保证报告里全是有效语料。
2. **回落确定性**：`fallback[ hash32(npc.id + '|' + normQ(q)) % len ]`——同问必同答，测试可以逐位断言。
3. **规则可达性探针**：测试用 `r.kws.join('！')` 作为问句——本规则命中数必然全池最高，绕开"关键词是别的规则子串"的误报。这是写确定性测试的实用技巧。

**语料纪律**：村民不许说出"差序格局""礼治"这些书里的学术名词（22 词黑名单，测试扫描 300+ 段语料零命中）。概念要由学生自己贴上去——这是教学设计，不是技术限制。

## 5. 空间语义分析：把"波纹"盖成房子

每处 SVG 要素带真值：`{ id:'f302', kind:'homes', name:'围屋同心圈层', truth:['c04a'], ask:{选项题+解析}, analysis:'讲解' }`。

分析器做的事：学生贴的概念标签 vs truth 求交——命中任一 =○，数量位置全对 =◎；得分 = `(命中标签数×2 + 观察题答对数) / (要素总数×2) × 100`。满分标注自动点亮该村的"地理发现"（围屋=差序格局的立体模型这类彩蛋）。

**踩坑记录**（都进了质检报告）：
- 村落真值会引用跨章概念（北方村的老槐树同时挂"无讼"和"长幼之序"），概念池若只收本村对口章就会**把真值过滤掉**——`conceptPool` 必须取"对口章 ∪ 真值 ∪ 发现 ∪ NPC 规则"的并集。
- `analyzeVillage` 自动入账"发现"时曾把对象当键存（`v.finds[obj]` → `'[object Object]'`），成就永远不可达——模拟通关测试（13 枚成就逐一解锁）抓出来的。

## 6. SVG 手绘地图：数据驱动的四个技巧

1. **百分比坐标系**：要素只存 `x,y ∈ [0,100]`，`viewBox="0 0 100 100"`，任何屏幕等比缩放。
2. **形状字库**：20 余种 `markerShape(kind)`（祠堂/鼓楼/茶馆/涝池…），每种是一个小 SVG 组——加新要素类型只需加一个 case。
3. **分类配色 + HTML 图例**：`catOf(kind)` 把要素按社会功能分五类配色（礼治朱红/教化墨绿/居住褐/生计橄榄/市集交通蓝灰），图例是图外面的 HTML（不进 SVG，避免与要素抢位置）。
4. **标签防遮挡**：`paint-order:stroke` + 宣纸色描边（`stroke="${ground}" stroke-width="1.1"`）——SVG 文字描边在填充之下的属性，一行解决手绘图标签可读性。

## 7. 批注、单文件版、打印壳（三件套）

- **批注**：`state.notes['c01#2']` 键值对 + `setNote`（500 字上限、首注 +1 分、清空即删）。保存后**就地更新 summary，绝不重渲染整页**——否则报告页 textarea 里未提交的正文会被冲掉。批注在 `buildReport` 第五节逐章汇入"我的批注「…」"。
- **单文件版**：`tools/build-single.mjs` 用 `html.replace(tag, () => code)` 的**函数式替换**——若用字符串替换，JS 里的 `${...}` 会被 `String.replace` 的 `$` 特殊序列吃掉（`$&`、`` $` ``），这是最容易翻车的坑。自检两道：`</script` 出现即拒绝、外链残留必须为 0。产物约 246KB，微信直接发。
- **打印壳**：`#print-sheet` 平时 `display:none`；`@media print` 里 `body * { visibility:hidden }` + `#print-sheet * { visibility:visible }` ——比"只渲染打印视图的新窗口"干净得多。

## 9. 扩展指南

- **加一章**：`data-book.js` 的 CHAPTERS 加一节（节选逐字摘自底本合并件），跑 test 自动核验引文；对口村落在 villages 侧同步。
- **加一村**：复制 `data-village-v1.js` 改造（要素带 truth、NPC 5 人 × ≥5 规则、语料过黑名单），`data-villages.js` 注册，test 第④组会替你查结构。
- **加成就**：`engine.js` 的 ACHIEVEMENTS 加判定函数（对空状态不得抛异常，第⑩组把关）。
- **改视觉**：只动 `css/style.css` 与 `ui.js` 装饰函数（heroSceneSVG/catOf/drawMap/villageDecor），引擎不受影响。
- **接 API**：设置页填 OpenAI 兼容地址即可，失败自动回落离线引擎并在气泡注明来源。
