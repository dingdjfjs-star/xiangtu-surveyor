1 · 三明治架构：为什么引擎必须零 DOM

架构总览与铁律

三条铁律：① engine.js 禁止 document./fetch（测试静态扫描）——所以 Node 里 node test\test.js 不开浏览器就能跑 914 项断言；② 数据文件同时挂 window.XT_* 与 module.exports；③ UI 不写业务判断，全委托引擎。

2 · 考据闭环：引文逐字可回查

抓底本 → 清洗 → 子串回归（全项目最硬的一环）

管线：抓取脚本（GBK 解码+顺页链）→ 原始存档 → 清洗成纯正文 → data-book.js 每条节选逐字摘录 → 测试对每条节选+每日一句做底本子串匹配，失配即红。

// test.js 第③组：引文回归（空白归一化后逐字子串）
const S = corpus[ch.id].replace(/\s+/g, '');
if (!S.includes(e.text.replace(/\s+/g, ''))) fail('底本失配');
实战教训：番茄小说版抓下来是「乡土农弯腰收割稻」式缺字——它用自定义字体做字符混淆，弃用留痕；改信国学导航全本，另对 5 句名句做搜索引擎独立抽查。网络流传"金句"多有拼接改写，一律以底本为准。
动手改：给某一章补一条节选——从 资料/底本合并/gx_*.txt 复制一句，贴进 data-book.js，跑 node test\test.js，测试会替你核验摘录是否逐字。

3 · 离线 NPC 引擎：确定性怎么设计

规则匹配 / 回落 / 可达性探针 / 语料纪律
// engine.js：命中数最多的规则胜出，并列取声明序 —— 同问必同答
function pickRule(npc, question) {
  const q = normQ(question);          // 去标点空白、转小写
  let best = null, bestHits = 0;
  for (const r of npc.rules) {
    let hits = 0;
    for (const kw of r.kws) if (q.includes(normQ(kw))) hits++;
    if (hits > bestHits) { best = r; bestHits = hits; }
  }
  return best;                        // 无命中 → 哈希轮转回落句，同问同答
}

三个关键决策：回落句不采集（闲聊不进素材库）；回落确定性（hash32(npc.id+'|'+q) % len，测试逐位断言）；可达性探针——测试用 r.kws.join('！') 当问句，本规则命中数必然全池最高，绕开"关键词是别的规则子串"的误报。

语料纪律：村民不许说出"差序格局""礼治"等 22 个学术词（测试扫描 300+ 段零命中）。概念要由学生自己贴——这是教学设计。

4 · 空间语义分析：把"波纹"盖成房子

要素真值 / 评分公式 / 两个踩坑
// 每处 SVG 要素带概念真值与观察题（节选）
{ id:'f302', kind:'homes', name:'围屋同心圈层',
  truth:['c04a'],                       // ← 差序格局的立体模型
  ask:{ q:'房间怎么排布？', options:[...], answer:1, exp:'…' },
  analysis:'建筑即社会图…' }

评分 = (命中标签数×2 + 观察题答对数) / (要素总数×2) × 100；满分标注自动点亮"地理发现"。

两个踩坑：①村落真值会引用跨章概念（北方村老槐树同时挂"无讼"和"长幼之序"），概念池若只收本村对口章就会把真值过滤掉——conceptPool 必须取「对口章 ∪ 真值 ∪ 发现 ∪ 规则」并集；②"发现"入账曾把对象当键（v.finds[obj] → '[object Object]'），成就永远不可达——模拟通关测试（15 枚成就逐一解锁）抓出来的。

6 · 三件套：批注 / 单文件版 / 打印壳

每件都有一个"最容易翻车的坑"

批注：state.notes['c01#2'] 键值对 + setNote（500 字上限、首注+1分、清空即删），报告第五节逐章汇入"我的批注「…」"。

坑：保存批注后不能重渲染整页——报告页 textarea 里未提交的正文会被冲掉。就地更新 summary。

单文件版：tools/build-single.mjs 把 css+9 个 js 内联进一个 HTML（237.7KB，微信直发）。

坑：html.replace(tag, code) 的字符串替换会把 JS 里的 ${...} 当 $ 特殊序列吃掉——必须用函数式替换 replace(tag, () => code)；另加两道自检：</script 出现即拒绝、外链残留必须为 0。

打印壳：#print-sheet 平时 display:none，@media print 里 body *{visibility:hidden} + #print-sheet *{visibility:visible}——不弹新窗口、不重排版。

// css/style.css
@media print {
  body * { visibility: hidden !important; }
  #print-sheet, #print-sheet * { visibility: visible !important; }
}
